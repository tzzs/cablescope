# 术语表与文案约定

> 中英文案的唯一参照。新增/修改用户可见文案前先查这里；同一个中文 key 在 App、Widget、
> CLI 三张译文表里必须译成同一个英文。

## 一、术语

| 中文（源语言 / key） | English | 说明 |
| --- | --- | --- |
| 雷雳 | Thunderbolt | Apple 官方简中译名。**不用"雷电"**（2026-10 前 README、IOKit 检查器、CLI 曾混用） |
| USB-C 端口 | USB-C Port | |
| 线缆 | cable | 不用"数据线"（纯充电线也是线缆） |
| e-marker | e-marker | 保持小写，不翻译、不首字母大写 |
| PD 合同 | PD Contract | 协商结果（电压 × 电流）。只认 `AdapterDetails.Current`；区别于电池侧功率（`Voltage` × `Amperage`） |
| PD 档位 / 选中档 | PD tier / selected tier | 充电器广告的 PDO（`Max Current` 是该档上限）。**不叫“协商档/合同”**：它不是 RDO 实际请求的电流 |
| 电池侧功率 | battery-side power | 顶层 `Voltage` × `Amperage`（流入电池的功率）。**不叫“瞬时功率/充电器输出”**：macOS 不提供端口级功率读数 |
| 已接通电源 | Plugged In | App 与 Widget 统一（此前 App 为 "Connected to Power"） |
| 使用电池 | On Battery | |
| 充电中 / 已暂停 | Charging / Paused | |
| 插头方向 A / B | Plug Orientation A / B | 对应 `PlugOrientation` 1 / 2。**不用"正向/反向插入"**：USB-C 正反都能插，"反向"读起来像插错了 |
| 评级 | rating | 由协商峰值推断，不是认证（见 CONTRIBUTING 文案红线） |
| 至少支持 5A | supports at least 5A | 5A 能力的**唯一**说法。**不要写"5A e-marker 线"**：5A 来自协商峰值推断，而 e-marker 芯片在该路径上从未被直读，复合断言里的后半句是外推。e-marker 芯片自身的读数走 `EMarkerSnapshot` → `eMarkerChips` 单独展示 |
| 写入 / 读取 | write / read | 测速。同一区块里不混用"写出/读出" |

## 二、英文大小写

- **Title Case**：窗口/区块标题、按钮、菜单项、开关标签、状态胶囊（`Plugged In`、`Check for Updates`）。
- **Sentence case**：完整句子、说明文字、脚注、通知正文（`No device on this port currently`）。
- 专有写法原样保留：`e-marker`、`USB4`、`DisplayPort`、`PD`。
- **USB 速率类别名保持英文**：`Low Speed` / `Full Speed` / `Hi-Speed` / `SuperSpeed` 以及
  `USB 2.0` / `USB 3.x Gen1` 这类，都是 USB 规范（USB 2.0 §5.1）自己定义的类别名，
  与 `USB4`、`HBR3` 同属"行业惯例中英文语境都保留原词"的协议规格术语，**不译**。
  对应代码：`CableKit/Models/CableSnapshot.swift` 的 `USBSpeed.generation`。
  这类值是**渲染时计算**的（不是快照里的固化字符串），但语言无关是有意为之，
  不要为了"中文界面全中文"而给它们加 `locale:` 参数。

## 三、拼接与格式

- **整句一个 key，不要 `Text + Text` 拼片段**。数值用 `\(value, format: …)` 插值，在
  `LocalizedStringKey` 里生成的就是 `%@`，如 `"系统输入 · %@V / %@A"`。拆成片段会让译文
  只能逐段对应、语序锁死。
- **分隔符也是文案**。不要 `.joined(separator: "；")` 这类中文标点——要么逐行展示，要么用
  语言无关的 ` · `。`check_localization.py` 会把只含中文标点的字面量也当成待翻译文案。
- **复数走 `en.lproj/Localizable.stringsdict`**，不要写 `device(s)`。调用处用
  `AppLocalization.format(_:locale:_:)`：复数分支由格式化时的 locale 决定，
  `String(format:)` 用的是系统 locale，中文系统下英文会一律落进 other（"1 devices"）。
- **日期/时间显式带 `locale`**：`Date.formatted()` 默认跟随系统而不是 App 语言。
