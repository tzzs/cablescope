# 产品定位与命名

## 一、产品定位

一款 macOS 菜单栏工具，用于检测当前连接的数据线（USB-C / 雷电）的全部能力：

| 能力维度 | 展示内容 |
| --- | --- |
| ⚡ 充电 | 当前充电功率（W）、电压/电流、PD 合同、PD 档位表（直读）、充电瓶颈归因、实时功率曲线 |
| 🔌 传输 | 协商的 USB 速率（USB 2.0 / 3.x / USB4 / 雷电）、设备↔物理端口归属、实测吞吐（规划） |
| 🖥 视频 | 是否承载 DisplayPort、协商链路速率、可驱动分辨率/刷新率 |
| 🏷 线缆身份 | **e-marker 直读**（线缆速度档/电流评级 3A·5A/产品类型）、基于历史协商峰值的评级推断 |

**核心卖点**：在 Apple Silicon 上直读 USB-C 端口控制器（AppleHPM），拿到 e-marker 芯片身份、PD 档位表与插拔状态，把"系统看到的协商结果"翻译成"这条线是什么、为什么充电慢"的解释；历史峰值评级作为无 e-marker 线缆的兜底推断。

## 二、应用名称（已确定）

**应用名称：CableScope**（中文副标题可用「线缆透视」）

- 理由：定位清晰（Cable = 域，Scope = 工具属性，"示波器/探测"呼应检测工具定位）、国际化命名、不与现有知名工具重名。
- Bundle ID：`com.cablescope.app`（正式使用时替换为公司域名，如 `com.yourteam.cablescope`）
- 视觉方向：菜单栏图标可设计成"示波器波形 + 插头"的组合。

### 命名原则（备选历史记录）

> 2026-09-13 已定稿为 CableScope。以下为决策时参考的命名原则与备选，仅作记录。

- 原则：简短好记、暗示"线缆/连接/探测"、避免与 Apple 商标（USB-IF 术语慎用为产品名）冲突、域名/App Store 可用。
- 备选：PlugProbe（Probe 强调探测）、PortLens（Lens 暗示看穿端口）、LiveWire（双关实时+线缆）、中文方向「满血线」等。

## 三、目标平台与形态

- **平台**：macOS 14+（Sonoma 起 `SMAppService`、IOKit API 稳定，2026-09-13 从 13 上调以解锁 `symbolEffect` 等 SwiftUI 能力）；端口控制器数据仅 Apple Silicon 可读，Intel/老机型自动降级为推断模式
- **形态**：菜单栏常驻 App（`MenuBarExtra`）+ 主详情窗口 + 桌面小组件（规划）
- **技术栈**：Swift 5.9+ / SwiftUI，纯原生，无第三方运行时依赖
- **分发（2026-09-13 定稿：全量开源，无付费版）**：
  - 同一代码库双渠道构建：**外部版**（全功能，含 CLI；Homebrew / GitHub Releases notarized DMG）与**商店版**（可选上架 MAS；受 Apple 规则自然受限——不带 CLI（Guideline 2.4.5）、必须 App Sandbox）
  - License 选 MIT/Apache-2.0（避开 GPL×MAS 不兼容）；可持续性走可选捐赠，不做付费墙
  - 商店版与外部版的功能差异只来自 Apple 规则，不人为阉割；Gate A 已验证 AppleHPM 读取在 App Sandbox 下可用，端口层数据双版本通用
